<br>

### Aims
- Create Area Charts about seaweed production in a world scale/europe scale and by production type (harvesting/aquaculture).
- Create Treemaps about seaweed species produced in companies in Europe by production type (harvesting/aquaculture).
- Create Bar chart about seaweed sales by country in Europe.
- Create a special bar chart about employement and sales projection.
### Infos
- For FAO data, This is production in volume only (tons) and we have data from 1950 to 2022.
- For JRC Data, they are based on sales (in euros) and number of companies. The data in treemaps are filtered with top 15 species (in number of companies identified) and consequently don't represent totally the species production diversities.
- For Seaweed Report 2025, The numbers used for the chart are based on an economic modelisation with the most optimistic scenario.
